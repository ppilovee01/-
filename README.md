# 🛍️ พ่อแม่ เบ็ดเตล็ด (Por Mae Bet Taled)
> **ร้านค้าออนไลน์สินค้าเบ็ดเตล็ดและของใช้ในบ้านยุคใหม่** 
> พัฒนาขึ้นด้วยสถาปัตยกรรมเว็บสมัยใหม่ เน้นความเรียบหรู ใช้งานง่าย และตอบสนองรวดเร็วในทุกอุปกรณ์

---

## 🎨 การออกแบบและการตกแต่ง (Design & Aesthetics)
ระบบได้รับการอัปเกรด GUI/UX ครั้งใหญ่ในธีม **Blue/Pastel Modern** เพื่อส่งมอบประสบการณ์ระดับพรีเมียมให้กับผู้ใช้งาน:
*   **โทนสีหลัก (Color Palette):**
    *   🔵 Main Accent: `#AEE2FF` (พาสเทลฟ้านุ่มนวล)
    *   🌀 Hover State: `#7FB5FF` (น้ำเงินโทนสว่าง)
    *   💮 Background Base: `#F0F8FF` (ขาวอมฟ้าอ่อนนุ่มตา)
*   **ตัวอักษร (Typography):** ใช้ฟอนต์ **Kanit** จาก Google Fonts มอบความโมเดิร์น อ่านง่าย และลงตัวกับทุกดีไซน์
*   **แอนิเมชัน (Animations):** เสริมเอฟเฟกต์ด้วย `animate.css` และหน้าต่างแจ้งเตือนแบบตอบสนองเร้าใจด้วย `SweetAlert2`

## ✨ คุณสมบัติของระบบ (Core Features)

### 🛒 สำหรับลูกค้า (Customer Interface)
1.  **หน้าแรกแนะนำสินค้า:**
    *   ระบบสไลด์ภาพแบนเนอร์โฆษณาเคลื่อนไหว
    *   ตัวกรองหมวดหมู่สินค้าแบบปัดสไลด์ตามแกนนอน (Scroll Menu) เหมาะกับสมาร์ทโฟน
    *   ช่องค้นหาสินค้าแบบ Real-time
2.  **หน้ารายละเอียดสินค้า (`product_detail.php`):**
    *   ระบบเลือกตัวเลือกสินค้า (Options) เช่น ขนาด สี ฯลฯ
    *   ฟังก์ชันปรับจำนวนสินค้าควบคุมปริมาณสต๊อกแบบเรียลไทม์
    *   ฟังก์ชันเก็บรายการสินค้าที่ชอบ (Wishlist) พร้อมอัปเดต UI ทันที
    *   ระบบรีวิวและให้คะแนนสินค้า (Rating Stars) เฉพาะลูกค้าที่ซื้อสินค้าแล้ว
3.  **หน้าตะกร้าสินค้าและการชำระเงินเต็มจอ (`cart.php`):**
    *   อัปเดตความกว้างเต็มจอ (12 คอลัมน์) เพื่อความโปร่งตาในการกรอกข้อมูล
    *   ระบบคำนวณเงินสด ส่วนลด และคูปองแบบเรียลไทม์
    *   สร้างรหัสสแกนจ่าย QR Code PromptPay อัตโนมัติคำนวณตามยอดสุทธิ
    *   ฟังก์ชันแนบภาพสลิปโอนเงินและระบบเลือกที่อยู่จัดส่งแบบเปิด Modal ในตัว
4.  **ระบบสมาชิกและประวัติการสั่งซื้อ:**
    *   ระบบตรวจสอบสถานะการส่งสินค้าและตัวจับเลขแทร็กกิ้ง (Tracking Code)
    *   ระบบจำลองการกู้คืนรหัสผ่าน (Forgot Password) พร้อมส่งอีเมลจำลองเพื่อตั้งรหัสผ่านใหม่
    *   จัดการสมุดที่อยู่ของฉันเพื่อประหยัดเวลาระหว่างเช็คเอาต์

### ⚙️ สำหรับผู้ดูแลระบบ (Admin Panel)
*   Dashboard สรุปยอดขาย จำนวนคำสั่งซื้อ และสินค้าคงเหลือแบบครอบคลุม
*   ระบบจัดการล็อตสินค้า (FIFO Lot Management) เพื่อติดตามวันนำเข้าและต้นทุนที่ถูกต้อง
*   ระบบออกใบปะหน้าพัสดุ (Print Shipping Label) สะดวกต่อการแพ็คสินค้า
*   ส่งการแจ้งเตือนคำสั่งซื้อใหม่และสลิปโอนเงินตรงไปยัง **Discord Webhook** ทันที

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)
ระบบทำงานบนฐานข้อมูล MySQL ชื่อ `fitness_db` โดยใช้ตารางหลักดังนี้:
*   `products` - ข้อมูลสินค้าเบ็ดเตล็ดหลัก
*   `product_lots` - ล็อตการนำเข้าสินค้า (รองรับระบบตัดสต๊อกแบบ FIFO)
*   `categories` - หมวดหมู่สินค้าทั่วไป (อาหารแห้ง, ของใช้ในบ้าน, ยาสามัญ ฯลฯ)
*   `orders` & `order_items` - ข้อมูลคำสั่งซื้อและรายการสินค้าในบิล
*   `user_addresses` - สมุดที่อยู่จัดส่งของลูกค้า
*   `payment_methods` - ช่องทางการโอนเงินที่เปิดใช้งาน
*   `wishlist` - รายการสินค้าที่ลูกค้าชื่นชอบ
*   `coupons` - คูปองส่วนลดพิเศษ

## 🚀 วิธีการติดตั้งและรันในเครื่อง (Local Deployment)

### 1. เครื่องมือที่ต้องเตรียม
1.  ติดตั้งโปรแกรม **XAMPP** (รองรับ PHP 8.1 หรือใหม่กว่า และ MySQL)
2.  โปรแกรมเว็บเบราว์เซอร์สมัยใหม่ (Chrome, Edge หรือ Safari)

### 2. ขั้นตอนการตั้งค่า
1.  ย้ายโฟลเดอร์โปรเจกต์นี้ไปไว้ในโฟลเดอร์ของจำลองเซิร์ฟเวอร์ XAMPP:
    ```bash
    C:\xampp\htdocs\FitGear
    ```
2.  เปิดโปรแกรม **XAMPP Control Panel** และกดสตาร์ทบริการ **Apache** และ **MySQL**
3.  นำเข้าฐานข้อมูล:
    *   เปิดบราวเซอร์ไปที่ `http://localhost/phpmyadmin`
    *   สร้างฐานข้อมูลใหม่ตั้งชื่อว่า `fitness_db`
    *   คลิกที่แท็บ **Import** (นำเข้า) และเลือกไฟล์ `fitness_db.sql` ในโฟลเดอร์โปรเจกต์ จากนั้นกดนำเข้า
4.  เปิดเว็บไซต์เพื่อใช้งานผ่านหน้าเบราว์เซอร์:
    ```url
    http://localhost/FitGear/index.php
    ```
