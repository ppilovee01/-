## 🎨 ระบบดีไซน์และสุนทรียศาสตร์ (Design Aesthetics)

ระบบได้รับการออกแบบโดยเน้นการผสมผสานความเรียบง่ายแบบมินิมอลกับสีสันสไตล์ **Blue/Pastel Modern** ที่ให้ความรู้สึกเป็นมิตรและพรีเมียม:

*   **โทนสีหลัก (Core Palette):**
    *   `--blue-main` (`#AEE2FF`): ฟ้าพาสเทลหลัก สว่าง สบายตา และดูน่าเชื่อถือ
    *   `--blue-hover` (`#7FB5FF`): ฟ้าโทนเข้มเมื่อนำเมาส์ไปชี้ เพิ่มมิติและการโต้ตอบ
    *   `--bg-soft` (`#F0F8FF`): ขาวอมฟ้าอ่อน (Alice Blue) ใช้เป็นพื้นหลังเพื่อลดความล้าของดวงตา
*   **ระบบฟอนต์ (Typography):** ใช้ **Kanit (Google Fonts)** เพื่อสไตล์โมเดิร์น ลายเส้นสะอาดสะอ้าน เหมาะกับภาษาไทยและภาษาอังกฤษ
*   **การเคลื่อนไหว (Micro-Animations):** ผสานพลังของ `Animate.css` ในการเปลี่ยนหน้าเว็บหรือเปิด Modal พร้อมปุ่มไลก์/บันทึกรายการโปรดที่เปลี่ยนสถานะทันทีเมื่อกดคลิก

## 💡 คุณสมบัติโดดเด่นของระบบ (Key Features)

### 👥 ประสบการณ์ฝั่งลูกค้า (Customer Journey)
*   **ระบบหน้าแรกพร้อมตัวกรองหมวดหมู่:** ค้นหาสินค้าง่ายๆ ผ่านแถบสไลด์หมวดหมู่แบบเลื่อนปัดตามแนวนอน (Horizontal Scroll Filter) และคัดกรองสินค้าขั้นสูงตามช่วงราคาและสินค้าพร้อมส่ง
*   **หน้ารายละเอียดสินค้าล้ำสมัย (`product_detail.php`):** เลือกรุ่น ขนาด สีของสินค้าผ่านอินเตอร์เฟสปุ่มกด (Radio Pill Buttons) แทนการใช้ Dropdown แบบเก่า พร้อมระบบสินค้าที่ดูล่าสุด (Recently Viewed) และระบบแนะนำสินค้าใกล้เคียง (Related Products)
*   **หน้าชำระเงินเต็มพิกัด (`cart.php`):** 
    *   ปรับปรุงพื้นที่เป็น **Full-Width 12-Column Layout** เพื่อลดความแออัดของข้อมูล
    *   ระบบคิดเงินอัปเดตราคาส่วนลดและยอดสุทธิอัตโนมัติเมื่อกดบวก/ลบจำนวนสินค้า
    *   **PromptPay Dynamic QR Code:** เจนเนอเรตคิวอาร์โค้ด EMVCo เกรดความมั่นคงทางการเงินพร้อมใส่ยอดสุทธิและคำนวณ Checksum ให้อัตโนมัติทางหน้าเว็บ สแกนแล้วยอดตรงทันทีผ่านทุกแอปธนาคาร
*   **ระบบตะกร้าสินค้าสไลด์ข้างอัจฉริยะ (Interactive Cart Drawer):** ตะกร้าสไลด์ด้านข้างขวาของจออัปเดตข้อมูลแบบเรียลไทม์ผ่าน AJAX ช่วยให้ดู ตรวจสอบ แก้ไขจำนวน หรือลบสินค้าได้โดยไม่ต้องโหลดหน้าเว็บใหม่
*   **ระบบส่งเมลแจ้งยอดอัตโนมัติ (Email Invoice Notification):** จัดส่งอีเมลสรุปคำสั่งซื้อและสลิปเงินด้วย HTML สวยงามสไตล์พาสเทลผ่านระบบ SMTP / PHPMailer ของร้านโดยอัตโนมัติ
*   **แถบติดตามสถานะการจัดส่ง 4 ขั้นตอน (Order Delivery Timeline):** แสดงขั้นตอนการจัดส่ง 'สั่งซื้อ -> เตรียมของ -> ขนส่ง -> สำเร็จ' พร้อมเลขพัสดุและลิงก์ประเมินรีวิวสินค้า
*   **ระบบ OTP รีเซ็ตรหัสผ่านผ่านอีเมล (Modern OTP Password Reset):** ลืมรหัสผ่านแบบเก่าและเปลี่ยนมาใช้รหัสยืนยัน OTP 6 หลักส่งเข้าอีเมลโดยตรงพร้อมวันหมดอายุภายใน 15 นาทีเพื่อความปลอดภัยระดับสากล

### 👑 ระบบบริหารจัดการหลังบ้าน (FIFO Stock & Business Intelligence)
*   **ระบบตัดสต๊อกแบบ FIFO (First-In, First-Out):** ป้องกันสต๊อกจมด้วยการตัดสินค้าล็อตที่เข้ามาก่อนเสมอผ่านตาราง `product_lots` บันทึกต้นทุนนำเข้าและวันหมดอายุล็อตเพื่อความละเอียด
*   **การแจ้งเตือนออเดอร์เข้าทันที (Discord Integration):** ส่งแจ้งเตือนการสั่งซื้อใหม่และสลิปเงินเข้าห้องเซิร์ฟเวอร์ Discord ทันที
*   **กระดิ่งแจ้งเตือนลูกค้าและแอดมิน (Notification Center):** ระบบส่งกล่องการแจ้งเตือนสด (Bell Notifications) อัปเดตผ่าน AJAX ทุกๆ 30 วินาที คอยแจ้งแอดมินเมื่อมีออเดอร์ใหม่/ความคิดเห็น และแจ้งลูกค้าเมื่อสถานะออเดอร์มีการอัปเดต
*   **แคมเปญ Flash Sale และจัดตารางเวลาอัตโนมัติ (Flash Sale Scheduler):** แผงควบคุมจัดแคมเปญลดราคาสินค้าตามเวลา พร้อมระบบรันแคมเปญสุ่มสินค้าที่มีสต๊อกมาลดราคาอัตโนมัติเมื่อคลังว่าง พร้อม progress bar แสดงยอดโควตา
*   **แดชบอร์ดสถิติกำไรสุทธิและชาร์ตประเภทสินค้า:** หน้าจอแอดมินแสดงยอดกำไรสุทธิตามหลักต้นทุนจริง FIFO พร้อมแผนภูมิวินโดว์ชาร์ตสัดส่วนยอดขายด้วย Chart.js
*   **ระบบส่งออกรายงานกรองยอดขายด้วย Excel (Financial Excel Export):** เลือกช่วงวัน, สินค้า และสถานะออเดอร์เพื่อส่งออกสรุปบัญชีพร้อมคอลัมน์ COGS (ต้นทุน) และ Net Profit (กำไรสุทธิ) พร้อมสรุปท้ายตารางอย่างแม่นยำ
*   **ระบบป้องกันข้อมูลซ้ำซ้อนและปุ่มกดค้าง (Double-Submit Prevention):** ล็อคระบบการประมวลผลฟอร์มและปุ่มกดเพื่อป้องกันลูกค้ากดบันทึกหรือจ่ายเงินซ้ำซ้อนขณะประมวลผลข้อมูล

## 🗄️ โครงสร้างข้อมูลตารางหลัก (Database Tables Overview)

| ชื่อตาราง | คำอธิบายหน้าที่การทำงาน |
| :--- | :--- |
| `products` | เก็บรายการสินค้า ข้อมูลรูปภาพ คำอธิบาย และราคากลางล่าสุด |
| `product_lots` | ล็อตสินค้า (ราคาซื้อ, ราคาขาย, จำนวนสต๊อกนำเข้า, วันที่นำเข้า) สำหรับ FIFO |
| `categories` | หมวดหมู่สินค้าเบ็ดเตล็ด (อาหารแห้ง, ของใช้ในบ้าน, เครื่องเขียน ฯลฯ) |
| `orders` | ประวัติการสั่งซื้อ ยอดสุทธิ วิธีการชำระเงิน และสถานะบิลพัสดุ |
| `order_items` | รายการย่อยในแต่ละออเดอร์ พร้อมออปชันเสริมที่ลูกค้าเลือก (เช่น สี/ขนาด) |
| `user_addresses` | สมุดที่อยู่จัดส่งของสมาชิกทุกคนเพื่อความสะดวกในการสั่งซื้อครั้งถัดไป |
| `payment_methods` | ช่องทางการโอนเงิน เลขที่บัญชีธนาคาร และเบอร์พร้อมเพย์รับเงิน |

## 🚀 ขั้นตอนการติดตั้งและรันใช้งานภายในเครื่อง (Local Installation)

### 🛠️ สิ่งที่ต้องเตรียมความพร้อม
1.  ติดตั้งโปรแกรมจำลองเว็บเซิร์ฟเวอร์ **XAMPP** (แนะนำเวอร์ชันที่ใช้ PHP 8.1 หรือสูงกว่า)
2.  เปิดใช้งาน MySQL Database

### 💻 ขั้นตอนลงโปรแกรม
1.  **คัดลอกไฟล์โปรเจกต์:** นำโฟลเดอร์โปรเจกต์ `FitGear` ไปวางไว้ใต้ไดเรกทอรีเว็บของ XAMPP:
    ```bash
    C:\xampp\htdocs\FitGear
    ```
2.  **เปิดเซิร์ฟเวอร์:** เปิดโปรแกรม **XAMPP Control Panel** แล้วคลิกปุ่ม **Start** ที่บริการ **Apache** และ **MySQL**
3.  **นำเข้าฐานข้อมูล (Import Database):**
    *   เปิดเว็บเบราว์เซอร์ไปที่ลิงก์: `http://localhost/phpmyadmin`
    *   กดสร้างฐานข้อมูลใหม่ (New Database) โดยตั้งชื่อว่า `fitness_db` และเลือก Collation เป็น `utf8_general_ci` หรือ `utf8mb4_general_ci`
    *   คลิกที่ฐานข้อมูล `fitness_db` -> กดเมนู **Import** ด้านบน -> เลือกไฟล์ `fitness_db.sql` ในเครื่อง -> กดปุ่ม **Import** (นำเข้า) ด้านล่างสุด
4.  **เปิดใช้งานเว็บไซต์:** พิมพ์ URL ด้านล่างนี้ในบราวเซอร์ของคุณเพื่อเริ่มต้นช้อปปิ้ง:
    ```url
    http://localhost/FitGear/index.php
    ```
