## 🎨 ระบบดีไซน์และสุนทรียศาสตร์ (Design Aesthetics)

ระบบได้รับการออกแบบโดยเน้นการผสมผสานความเรียบง่ายแบบมินิมอลกับสีสันสไตล์ **Blue/Pastel Modern** ที่ให้ความรู้สึกเป็นมิตรและพรีเมียม:
*   **โทนสีหลัก:** Blue & Pastel Tone ให้ความรู้สึกเรียบหรู ดูแลความสะอาดตา สบายใจ และน่าเชื่อถือ
*   **องค์ประกอบโมเดิร์น:** ใช้ลูกเล่นกระจกฝ้า (Glassmorphism), เงาบางเบาแบบฟุ้งซอฟต์ (Soft Shadows), และการเปลี่ยนผ่านการเคลื่อนไหวเล็กน้อย (Micro-animations) บนส่วนประกอบต่างๆ เพื่อดึงดูดสายตาและทำให้น่าใช้งาน

## 👥 ประสบการณ์ฝั่งลูกค้า (Customer Journey & Features)

*   **ระบบป๊อปอัปข้อเสนอพิเศษต้อนรับ (Welcome Promo Pop-up):** แสดงป๊อปอัปคูปองต้อนรับส่วนลดพิเศษ (เช่น `WELCOME100` หรือคูปองส่งฟรี) ทันทีที่เข้าสู่หน้าแรกครั้งแรกในแต่ละเซสชัน พร้อมฟังก์ชันกดเคลมคูปองและบันทึกลงสิทธิ์ตะกร้าโดยอัตโนมัติด้วย AJAX
*   **ระบบตะกร้าสินค้าสไลด์ข้างและการซิงค์ข้อมูลสองทาง (Interactive Cart Drawer with Two-way Sync):** ตะกร้าสไลด์ด้านข้างขวาของจอแสดงผลแบบเรียลไทม์ และได้รับการซิงโครไนซ์ข้อมูลแบบสองทาง (Two-way Real-time Sync) กับหน้าตะกร้าสินค้าหลัก (`cart.php`) อย่างสมบูรณ์ การปรับปริมาณหรือลบสินค้าจะอัปเดตยอดเงิน ช่องอินพุต และคิวอาร์พร้อมเพย์บนหน้าหลักทันที และการแก้ไขข้อมูลในหน้าจอหลักจะซิงค์กลับไปที่สไลด์ข้างโดยไม่ต้องโหลดหน้าใหม่
*   **ป๊อปอัปเลือกตัวเลือกด่วนระดับพรีเมียม (Premium Quick Add Option Modal Upgrade):** พัฒนาหน้าต่างเลือกออปชันตัวเลือกสินค้าให้พรีเมียมยิ่งขึ้น แสดงข้อมูลสินค้าครบครัน (รูปภาพสินค้า, ราคาโปรโมชัน/Flash Sale, จำนวนคงเหลือในสต็อก) พร้อมระบบปุ่มกดลบ/บวกปรับแต่งจำนวน (Qty) ในตัวพร้อมระบบล็อกยอดตามจำนวนในสต็อกจริง
*   **คูปองส่วนลดแบบคลิกใช้ทันที & คูปองส่งฟรี (Coupon Selector & Free Shipping Coupon):** แสดงคูปองส่วนลดที่พร้อมใช้งานและเข้าเงื่อนไขทั้งหมดผ่าน Modal แบบกระจกใสบนหน้าตะกร้าสินค้า (`cart.php`) รองรับส่วนลดแบบจำนวนเงินสด ส่วนลดเปอร์เซ็นต์ และสิทธิ์จัดส่งฟรี โดยระบบจะคำนวณและหักค่าจัดส่งอัตโนมัติ พร้อมระบบตั้งค่าและตรวจสอบวันและเวลาเริ่ม/หมดอายุใช้งานคูปองอย่างแม่นยำระดับชั่วโมงและนาที (Precise DateTime Start/Expiry Validation) ผ่านช่องกรอกอินพุตแบบ `datetime-local` ในแผงควบคุมแอดมิน เพื่อป้องกันไม่ให้มีผู้นำโค้ดไปใช้ก่อนเริ่มแคมเปญหรือหลังหมดเวลาแม้แต่นาทีเดียว
*   **ระบบแต้มสะสมสมาชิกแลกส่วนลด (Loyalty Member Points):**
    *   ลูกค้าสามารถสะสมแต้มจากการสั่งซื้อ (คำนวณแบบไดนามิกตามเงื่อนไขแอดมิน)
    *   ลูกค้าสามารถใช้แต้มแลกรับส่วนลดแทนเงินสดได้จริงที่หน้าชำระเงิน โดยระบบมีกลไกจำกัดไม่ให้หักแต้มสะสมเกินความจำเป็น (`ceil(ยอดเงิน / อัตราส่วนแลกแต้ม)`)
    *   หน้าตั้งค่าบัญชี (`profile.php`) มีแท็บ **"ประวัติบัญชี & แต้มสะสม"** เพื่อให้ลูกค้าตรวจเช็คแต้มปัจจุบัน สมุดประวัติการบันทึกคะแนนเข้า-ออก (Points Ledger) แบบแยกโค้ดสี รวมถึง Timeline แสดงประวัติกิจกรรมการตั้งค่าบัญชีเพื่อความโปร่งใสและปลอดภัย
*   **ระบบเปรียบเทียบคุณสมบัติสินค้า (Product Comparison Floating Bar):** กล่องเลือกติ๊ก "เทียบ" บนการ์ดสินค้า สามารถเลือกเปรียบเทียบข้อมูลสเปกสินค้าได้สูงสุด 3 รายการพร้อมกัน โดยจะแสดงรายละเอียดเปรียบเทียบในรูปแบบตารางกระจกฝ้า (Glassmorphic Spec Matrix Table) ด้านล่าง
*   **แถบติดตามสถานะการจัดส่งพัสดุจำลองพร้อมระบบนำทาง (Visual Stepper & Carrier Tracking):**
    *   การแสดงความคืบหน้าการจัดส่งในหน้าบัญชีผ่านแถบความก้าวหน้า (`step-progress-line`) สีพาสเทลวิ่งไปข้างหน้าตามสถานะจริง
    *   แสดงข้อมูลผู้ให้บริการขนส่ง (ไปรษณีย์ไทย, KEX, Flash, J&T) ที่แอดมินเลือก และมีปุ่มอำนวยความสะดวก **"ติดตามพัสดุผ่านระบบ 17Track 📦"** เพื่อตรวจเช็คสถานะได้ทันที พร้อมไอคอนกดคัดลอกหมายเลขแทร็ก
*   **พิมพ์ใบเสร็จและใบเสร็จรับเงินอย่างย่อ (Print Invoice & Receipt):** ลูกค้าและแอดมินสามารถสั่งพิมพ์ใบเสร็จ/ใบกำกับภาษีอย่างย่อในรูปแบบกระดาษหรือบันทึกเป็นไฟล์ PDF ได้อย่างสะดวกสวยงามด้วยหน้าสำหรับพิมพ์ใบเสร็จสินค้า
*   **PromptPay Dynamic QR Code:** เจนเนอเรตคิวอาร์โค้ด EMVCo เกรดความมั่นคงทางการเงินพร้อมใส่ยอดสุทธิและคำนวณ Checksum ให้อัตโนมัติทางหน้าเว็บ สแกนแล้วยอดตรงทันทีผ่านทุกแอปธนาคาร
*   **ระบบรีวิวสินค้าโดยแนบรูปถ่ายจริง (Product Reviews with Image Upload):** ลูกค้าสามารถให้คะแนนดาว (1-5 ดาว) พร้อมแนบรูปถ่ายจริงของสินค้าจากหน้าประวัติการสั่งซื้อ และสามารถคัดกรองรีวิวตามระดับดาวหรือรีวิวที่มีรูปภาพได้อย่างมีไดนามิกผ่าน AJAX
*   **ระบบสลับธีมสีขาว/ดำ (Light/Dark Mode Theme Switcher):** ปุ่มสลับดีไซน์โทนสีพาสเทลสว่างและโทนอวกาศมืดสลัวที่มุมขวาบนของแถบเมนู พร้อมระบบวิเคราะห์ความชอบในเบราว์เซอร์ (`localStorage`) และการป้องกันสีแฟลชสว่างวาบขณะเปลี่ยนหน้าด้วยสคริปต์ตรวจเช็คตั้งแต่แท็กเปิด `<body>` (Inline Blocking Script) โดยความร่วมมือด้านดีไซน์แบบพรีเมียม ปรับสีสันให้เป็นโทน Midnight-Obsidian ครามลุ่มลึกพร้อมความเงาวิบวับ (Glow Effects) และป้ายปุ่มที่มีความเข้มคอนทราสต์ชัดเจนอ่านง่ายบนหน้าประวัติออเดอร์ หน้าตั้งค่าบัญชี และหน้าตะกร้าสินค้า (`cart.php`) โดยขจัดโครงสีขาวแบบ Hardcoded ออกทั้งหมดและจัดระดับคอนทราสต์ของกล่องรายละเอียดชำระเงินและป๊อปอัปคูปองอย่างลงตัว
*   **ระบบวิเคราะห์และแนะนำคูปองที่คุ้มที่สุดอัตโนมัติ (Best Coupon Auto-Recommendation):** ระบบช่วยประหยัดเงินลูกค้าหน้าตะกร้าสินค้า โดยวิเคราะห์หาคูปองที่ดีที่สุดที่ให้สิทธิ์ประโยชน์ลดราคาสูงสุด (หักลบประเภทเงินสด เปอร์เซ็นต์จำกัดสูงสุด หรือโค้ดส่งฟรี) จากนั้นแสดงแบนเนอร์แนะนำคูปองพร้อมปุ่มกดใช้โค้ดแนะนำด่วนในคลิกเดียว (Quick Apply Action) ที่ซิงค์การรันฟอร์มผ่าน JavaScript เพื่อคงระบบความปลอดภัยป้องกันภัยคุกคาม CSRF ไว้อย่างสมบูรณ์แบบโดยไม่มีโครงสร้างฟอร์มซ้อนทับกัน (Form Nesting Fix)
*   **ระบบรีวิวที่มีประโยชน์และจัดอันดับโดยสังคม (Helpful Review Rating System):** เพิ่มคะแนน Social Proof บนความเชื่อมั่นของสินค้า ลูกค้าคนอื่นสามารถกดคะแนนโหวต "มีประโยชน์ (Helpful)" หรือยกเลิกโหวตให้กับความเห็นของเพื่อนๆ ได้ โดยระบบป้องกันโหวตซ้ำ 1 คนต่อ 1 โหวตด้วยตารางโหวต และจัดอันดับการแสดงรีวิวที่มีคะแนนโหวตสูงที่สุดขึ้นมาด้านบนสุดก่อนตามลำดับ
*   **ภาพสไลด์สินค้าแนะนำตามอัลกอริทึม (Premium Cross-Selling Products Slider):** ปรับโฉมแผงแนะนำสินค้าล่างหน้ารายละเอียดสินค้า ดึงดูดความสนใจลูกค้าด้วยการวิเคราะห์ดึงสินค้าหมวดหมู่เดียวกัน ผสมผสานสินค้าที่ขายดีที่สุดในร้านมาแสดงรวมกันไม่เกิน 8 รายการ นำเสนอในแบบภาพสไลด์เลื่อนขวาแบบแนวนอน (Horizontal Touch Scroll Menu Card) เพื่อเพิ่มโอกาสการขายต่อเนื่อง (Cross-Selling)
*   **ระบบตรวจสอบสลิปโอนเงินอัจฉริยะด้วย AI (AI Slip Verification System):**
    *   **รองรับ AI หลายค่าย (Multi-Provider AI support):** แอดมินสามารถเลือกและสลับผู้ให้บริการ AI ได้ถึง 3 ค่าย ได้แก่ OpenAI (GPT-4o mini), Google Gemini (Gemini 2.5 Flash), และ Anthropic Claude (Claude 3.5 Haiku) พร้อมจัดการบันทึก API Key แยกกันได้อย่างอิสระผ่านเมนูตั้งค่าหลังบ้าน (`admin_settings.php`)
    *   **ป้องกันการทุจริตแบบเรียลไทม์ (Real-Time Fraud Prevention):** ระบบจะสแกนและวิเคราะห์สลิปอัตโนมัติขณะทำรายการสั่งซื้อ โดยตรวจสอบว่ารูปภาพเป็นสลิปโอนเงินจริงหรือไม่ (`is_slip`), ยอดเงินโอนตรงกับยอดสินค้าในคำสั่งซื้อจริงหรือไม่ (`amount_match`), และชื่อผู้รับเงินในสลิปตรงกับชื่อบัญชีร้านค้าที่เลือกจ่ายเงินหรือไม่ (`receiver_name_match`) หากตรวจพบความผิดปกติอย่างใดอย่างหนึ่ง (เช่น ยอดไม่ตรง หรือผู้รับโอนไม่ใช่ร้านค้า) ระบบจะปฏิเสธการทำออเดอร์ทันที
    *   **ระบบรองรับเมื่อเกิดข้อผิดพลาด (Graceful Fail-safe & Admin Alerts):** หากเกิดกรณีระบบล่ม, API Key ผิดพลาด หรือไม่มีอินเทอร์เน็ตในการเชื่อมต่อเซิร์ฟเวอร์ AI ระบบจะผ่อนปรนให้การสั่งซื้อดำเนินต่อไปได้ (ลูกค้าไม่สะดุด) แต่ระบบจะบันทึกสถานะลงฐานข้อมูลเป็น `error` และติดธงเตือนแอดมินด้วยไอคอนความปลอดภัย ⚠️ 😱 ในหน้าจัดการคำสั่งซื้อ (`admin_orders.php`) พร้อมมีข้อความอธิบายสาเหตุข้อผิดพลาดแสดงในรูปแบบ Tooltip อย่างชัดเจน
    *   **สั่งสแกนย้อนหลังและลองสแกนใหม่ (Admin Scan Retry):** แอดมินมีปุ่ม `🤖 ลองสแกนใหม่` สำหรับออเดอร์ที่เคยสแกนพลาดหรือเกิดข้อผิดพลาดในระบบ ทำให้สามารถเลือกส่งตรวจเช็คซ้ำกับ AI ตัวอื่นหรือคีย์ตัวใหม่ได้ทันที

### 👑 ระบบบริหารจัดการหลังบ้าน (FIFO Stock & Business Intelligence)

*   **ระบบตัดสต๊อกแบบ FIFO (First-In, First-Out):** ป้องกันสต๊อกจมด้วยการตัดสินค้าล็อตที่เข้ามาก่อนเสมอผ่านตาราง `product_lots` บันทึกต้นทุนนำเข้าและวันหมดอายุล็อตเพื่อความละเอียดของงบการเงิน
*   **การจัดการคำสั่งซื้อผ่านระบบ Realtime AJAX (AJAX Admin Orders Control):** อัปเดตสถานะการสั่งซื้อ บันทึกโน้ต หรือบันทึกเลขพัสดุและประเภทขนส่งผ่านเบื้องหลังแบบ AJAX โดยหน้าเว็บไม่ต้องโหลดใหม่ พร้อมอัปเดตสถิติ Dashboard และไอคอนต่างๆ ทันที
*   **ระบบพิมพ์ฉลากใบปะหน้าสินค้าจัดส่งพร้อม QR Code (Order Shipping Label with Dynamic QR Code):** แผงพิมพ์ฉลากที่มีภาษาไทยและสระบนหน้าฉลากที่ถูกต้องครบถ้วน แสดงข้อมูลตัวเลือกย่อยของสินค้า และภาพ QR Code สำหรับสแกนรหัสสั่งซื้อเพื่อความรวดเร็วในการแพ็คสินค้า
*   **ตัวกรองช่วงเวลาวิเคราะห์ข้อมูลแดชบอร์ดแอดมิน (Admin Dashboard Date-Range Filters):**
    *   เลือกวิเคราะห์ยอดขายและกำไรสุทธิ (FIFO) ตามเงื่อนไขเวลา เช่น 7 วันล่าสุด, 30 วันล่าสุด, เดือนนี้, ปีนี้ หรือกำหนดช่วงเวลาเอง (Custom)
    *   แดชบอร์ด ตัวเลขตัวชี้วัด กราฟแนวโน้มยอดขาย และแผนภูมิวงกลมสัดส่วนประเภทสินค้าด้วย Chart.js จะทำการอัปเดตข้อมูลแบบเรียลไทม์โดยไม่ต้องรีโหลดหน้าเว็บ
*   **ระบบเก็บบันทึกประวัติการทำงานหลังบ้าน (Admin Activity Logs & Audit Trail):**
    *   ตารางเก็บบันทึกประวัติการทำกิจกรรมแอดมินและลูกค้าอย่างละเอียด (การจัดการสินค้า/คลังสินค้าล็อต FIFO, ออเดอร์, คูปอง, แคมเปญ Flash Sale, ช่องทางการชำระเงิน, รีวิวสินค้า และการตั้งค่าระบบ ฯลฯ)
    *   **การแสดงข้อมูลแบบละเอียดสูง (High-Resolution Diffs):** เปรียบเทียบข้อมูลก่อนและหลังการแก้ไข (Old vs. New values) เช่น ชื่อสินค้า, สต๊อก, ราคาขาย, อัตราแต้มสะสม, ระดับสิทธิ์, การตั้งค่าการชำระเงิน หรือแคมเปญ Flash Sale โดยระบบจะคำนวณส่วนต่างและตรวจจับความเปลี่ยนแปลงเฉพาะฟิลด์ พร้อมทำการซ่อนข้อมูลที่เป็นความลับ
    *   **ระบบสรุปด่วนและแผงเปรียบเทียบ (Quick Summary & Collapsible Diff Tables):** แสดงหัวข้อข้อมูลที่เปลี่ยนโดยย่อทันทีในตาราง และมีปุ่มขยายการแสดงผลแบบตาราง Collapsible เพื่อดูความต่างสีแดง (ค่าเก่า) / สีเขียว (ค่าใหม่) ได้อย่างสะดวกสบาย
    *   แสดงข้อมูลประเภทกิจกรรม IP Address ประทับเวลา และบทบาทผู้ทำรายการแบบติดป้ายสีเด่นชัด
    *   ปุ่มล้างประวัติที่ปลอดภัยสูง โดยแอดมินจะต้องป้อนรหัสผ่านบัญชีแอดมินปัจจุบันเพื่อยืนยันตัวตนก่อนดำเนินการ
*   **แคมเปญ Flash Sale และจัดตารางเวลาอัตโนมัติ (Flash Sale Scheduler):** แผงควบคุมจัดแคมเปญลดราคาสินค้าตามเวลา พร้อมระบบรันแคมเปญสุ่มสินค้าที่มีสต๊อกมาลดราคาอัตโนมัติเมื่อคลังว่าง พร้อม progress bar แสดงยอดโควตา
*   **ระบบส่งออกรายงานกรองยอดขายด้วย Excel (Financial Excel Export):** เลือกช่วงวัน, สินค้า และสถานะออเดอร์เพื่อส่งออกสรุปบัญชีพร้อมคอลัมน์ COGS (ต้นทุน) และ Net Profit (กำไรสุทธิ) พร้อมสรุปท้ายตารางอย่างแม่นยำ
*   **คอนโซลจัดการรีวิวหลังบ้านและการทำความสะอาดข้อมูลอัตโนมัติ (Admin Reviews Console & File Auto-Cleanup):** แผงควบคุมตรวจเช็ครีวิวและสลิปภาพถ่ายจริงของลูกค้าที่ส่งเข้ามา โดยหากแอดมินลบรีวิวที่ไม่เหมาะสม ระบบจะลบไฟล์รูปภาพออกจากโฟลเดอร์ `uploads/` บนเซิร์ฟเวอร์โดยอัตโนมัติเพื่อป้องกันเนื้อที่เต็ม
*   **การแจ้งเตือนออเดอร์เข้าทันที (LINE Notify & Discord Webhook Integration):** ส่งแจ้งเตือนการสั่งซื้อใหม่และสลิปเงินเข้ากลุ่ม LINE ของผู้ดูแลระบบ และห้องเซิร์ฟเวอร์ Discord ทันทีที่มีออเดอร์ใหม่เข้ามา
*   **ระบบป้องกันข้อมูลซ้ำซ้อนและปุ่มกดค้าง (Double-Submit Prevention):** ล็อคระบบการประมวลผลฟอร์มและปุ่มกดเพื่อป้องกันลูกค้ากดบันทึกหรือจ่ายเงินซ้ำซ้อนขณะประมวลผลข้อมูล

## 🔒 สถาปัตยกรรมความปลอดภัยและการปกป้องระบบ (Enterprise Security Hardening)

เราได้ดำเนินการตรวจสอบความปลอดภัยรอบด้านและแก้ไขปิดช่องโหว่ความปลอดภัยสำคัญ 4 ประเภทหลักตามมาตรฐานสากล:

1.  **การป้องกัน Remote Code Execution (RCE) ในโฟลเดอร์อัปโหลด:**
    *   สร้างไฟล์ [uploads/.htaccess](file:///c:/xampp/htdocs/FitGear/uploads/.htaccess) เพื่อปิดกั้นการรันคำสั่งสคริปต์ PHP และ CGI ทั้งหมดในโฟลเดอร์เก็บสื่อ พร้อมสั่งปิด Directory Listing ป้องกันการสแกนโครงสร้างแฟ้มข้อมูล
    *   ติดตั้งระบบตรวจสอบและกรองเฉพาะนามสกุลไฟล์รูปภาพที่ได้รับอนุญาตเท่านั้น (`jpg`, `jpeg`, `png`, `gif`, `webp`, `ico`) สำหรับการอัปโหลดรูปสินค้า รูปเกี่ยวกับเรา แบนเนอร์ ไอคอนร้าน และใบสลิปโอนชำระเงิน
2.  **การป้องกัน SQL Injection (SQLi):**
    *   บังคับทำการกรอง แปลงประเภทข้อมูลเป็นตัวเลขจำนวนเต็มด้วย `intval()` และทำการใช้ `mysqli_real_escape_string()` สำหรับพารามิเตอร์ข้อความ GET/POST ทุกช่องทางในหน้าควบคุมหลัก (คูปอง, การชำระเงิน, ข้อมูลผู้ใช้, ฟีดแบ็ก, สถานะพัสดุ, แดชบอร์ดวิเคราะห์ช่วงเวลา ฯลฯ)
3.  **การป้องกัน Insecure Direct Object Reference (IDOR):**
    *   ระบบประมวลผลการจัดส่งจะผูกเงื่อนไข ID ที่อยู่จัดส่งคู่กับ Session User ID ที่สั่งซื้อและยืนยันตัวตนในระบบจริงเท่านั้น ป้องกันสิทธิ์การระบุที่อยู่อื่นเพื่อเจาะแกะข้อมูลของสมาชิกผู้อื่นในฐานข้อมูล
4.  **การป้องกัน Cross-Site Scripting (XSS):**
    *   ใช้ฟังก์ชัน `htmlspecialchars()` ห่อหุ้มตัวแปรข้อความทุกจุดที่นำข้อมูลซึ่งกรอกโดยผู้ใช้มาแสดงผลทางหน้าจอ (เนื้อหารีวิวสินค้า, ข้อมูลรายละเอียดที่อยู่จัดส่งของลูกค้า, คำแปลข้อความใบปะหน้า, โน้ตความเห็นลูกค้า ฯลฯ) ป้องกันการฝังโค้ดสคริปต์ทำลายความปลอดภัยของเว็บ
5.  **การป้องกัน Cross-Site Request Forgery (CSRF Protection):**
    *   **CSRF Engine Core:** พัฒนาระบบขับเคลื่อน Token ความปลอดภัยส่วนกลางใน [db.php](file:///c:/xampp/htdocs/FitGear/db.php) ด้วยกลไกสร้าง Token ประจำตัวผู้ใช้งานเก็บไว้ในเซสชัน (`$_SESSION['csrf_token']`) พร้อมฟังก์ชันตรวจเช็คที่ปลอดภัยจากการเปรียบเทียบเวลา (Timing Attacks) ด้วยการใช้ `hash_equals()`
    *   **State-Changing Form Protection:** ทุกๆ ฟอร์มที่เป็นการ POST ข้อมูลเพื่อบันทึกหรือเปลี่ยนค่าในฐานข้อมูล (เช่น ฟอร์มสมัครสมาชิก, ฟอร์มล็อกอิน, เปลี่ยนรหัสผ่าน, ยื่นรีวิวสินค้า, กดใช้งานคูปองส่วนลด, การสั่งซื้อสินค้าฝั่งลูกค้า และฟอร์มสร้างสินค้า, ลบล็อตสินค้า, ตั้งค่าระบบ Flash Sale, บันทึกการตั้งค่าร้านค้าฝั่งแอดมิน) จะต้องฝัง `get_csrf_input()` เพื่อส่ง Token ไปตรวจสอบทุกครั้ง
    *   **Mutating GET Protection:** ป้องกันคำสั่งด่วนผ่านลิงก์คลิก URL (Mutating GET Parameters) เช่น การลบสินค้า (`?delete=ID`), ลบล็อตสินค้า (`?delete_lot=ID`), ลบคูปอง (`?del=ID`), ลบหมวดหมู่สินค้า, ลบข้อความติดต่อลูกค้า, ลบแบนเนอร์, ลบช่องทางชำระเงิน, ยกเลิกแคมเปญ Flash Sale รวมถึงการยกเลิกออเดอร์ของฝั่งลูกค้า โดยระบบจะมีการฝัง `&csrf_token=...` เข้าไปในลิงก์และใช้ SweetAlert ยืนยันพารามิเตอร์ และตรวจสอบ Token บนระบบเซิร์ฟเวอร์อย่างเข้มงวดก่อนอนุญาตให้ลบข้อมูล
    *   **AJAX CSRF Token Integration:** ฝัง Meta Tag `<meta name="csrf-token" content="...">` บนส่วนหัว `<head>` ของ [header.php](file:///c:/xampp/htdocs/FitGear/header.php) เพื่อให้สคริปต์ JavaScript ในหน้าต่างๆ ดึงคีย์นี้ไปแนบใน AJAX Request ได้อย่างสะดวกและปลอดภัย ทำให้ระบบอัปเดตแบบเรียลไทม์ เช่น การล้างแจ้งเตือน, การลบที่อยู่จัดส่ง, หรือระบบอัปเดตเลขพัสดุผ่าน AJAX ฝั่งแอดมิน ได้รับการป้องกันอย่างสมบูรณ์แบบ
6.  **การป้องกัน DDoS และการเสริมความแข็งแกร่งของ HTTP (DDoS Mitigation & HTTP Hardening):**
    *   **Root .htaccess Rule:** ติดตั้งไฟล์ [.htaccess](file:///c:/xampp/htdocs/FitGear/.htaccess) ในโฟลเดอร์หลักของโปรเจกต์ เพื่อควบคุมและบล็อกการโจมตีระดับเซิร์ฟเวอร์
    *   **Application-Layer DDoS / Payload Size Restriction:** จำกัดขนาดข้อมูล Request Body ผ่านคำสั่ง `LimitRequestBody 10485760` (สูงสุด 10MB) ป้องกันการโจมตีประเภท Flood ด้วยข้อมูลขนาดใหญ่เพื่อส่งผลต่อหน่วยความจำและ CPU ของเซิร์ฟเวอร์ (Resource Exhaustion)
    *   **Sensitive Source & Config File Protection:** ป้องกันการสแกนและดึงไฟล์สำคัญโดยตรงจากภายนอก เช่น ไฟล์รหัสเชื่อมต่อนิรภัย [db.php](file:///c:/xampp/htdocs/FitGear/db.php), ไฟล์ฐานข้อมูลสำรอง `fitness_db.sql`/`fitness_dbd.sql`, โฟลเดอร์ `scratch/` และประวัติการทำงาน [README.md](file:///c:/xampp/htdocs/FitGear/README.md) เพื่อหลีกเลี่ยงการแกะโครงสร้างและข้อมูลของระบบ
    *   **HTTP Security Headers Defense-in-depth:** บังคับใช้ส่วนหัวความปลอดภัยระดับสากล ได้แก่:
        *   `X-Content-Type-Options "nosniff"`: ป้องกันช่องโหว่ MIME Sniffing และการหลอกประมวลผลไฟล์อันตราย
        *   `X-Frame-Options "SAMEORIGIN"`: ป้องกันการโจมตีแบบ Clickjacking ที่นำเว็บไปแสดงผลซ้อนใน iFrame ของเว็บผู้ไม่ประสงค์ดี
        *   `X-XSS-Protection "1; mode=block"`: สั่งการให้เว็บเบราว์เซอร์บล็อกการเรนเดอร์เพจทันทีหากตรวจพบการยิงสคริปต์ XSS เข้ามาในคำขอ
        *   `Referrer-Policy "strict-origin-when-cross-origin"`: ควบคุมการส่งข้อมูลส่วนหัว Referrer ป้องกันการรั่วไหลของ URL ปลายทางที่ละเอียดอ่อน
7.  **การแยกข้อมูลสำคัญและความลับผ่านสภาพแวดล้อม (Environment Variables - `.env`):**
    *   **ความปลอดภัยของข้อมูลลับ:** ข้อมูลสำคัญที่อ่อนไหว เช่น ข้อมูลเชื่อมต่อฐานข้อมูล MySQL, รหัสผ่าน SMTP ของเซิร์ฟเวอร์ส่งอีเมล, LINE Notify Token และ API Keys สำหรับบริการสแกนสลิปอัจฉริยะ (OpenAI, Gemini, Claude) จะถูกแยกเก็บไว้ในไฟล์ `.env` นอกโฟลเดอร์ซอร์สโค้ดหลัก เพื่อไม่ให้อัปโหลดขึ้น Git Repository ผ่านการกรองในไฟล์ `.gitignore`
    *   **กลไกตรวจสอบและรองรับการทำงาน (Graceful Fail-safe / Masking):**
        *   มีฟังก์ชันโหลดสภาพแวดล้อม `loadEnv()` และ `getSecretValue()` คอยอำนวยความสะดวกในการใช้งาน หากคีย์หรือสภาพแวดล้อมใดหายไป ระบบจะพยายามดึงค่าสำรองจากตารางในฐานข้อมูลเป็นตัวเลือกถัดไปโดยอัตโนมัติเพื่อให้โปรเจกต์ยังสามารถทำงานได้ตามปกติ
        *   **การปกป้องการแอบมองหน้าจอ (Credentials Masking):** ฟังก์ชัน `getMaskedValue()` จะทำการเซนเซอร์คีย์หรือรหัสผ่านที่มีความลับ เช่น แสดงผลในรูปแบบ `AIzaSy••••••••4fG` หรือ `sk-ant-••••••••55a` เมื่อเรนเดอร์ในเมนูตั้งค่าหลังบ้าน ช่วยจำกัดสิทธิ์การแอบดูหรือรั่วไหล และจะแปลงค่าเป็นสถานะปลอดภัยเมื่อบันทึกลงประวัติ Logs เสมอ

| `user_addresses` | สมุดที่อยู่จัดส่งของสมาชิกทุกคนเพื่อความสะดวกในการสั่งซื้อครั้งถัดไป |
| `payment_methods` | ช่องทางการโอนเงิน เลขที่บัญชีธนาคาร และเบอร์พร้อมเพย์รับเงิน |
| `admin_logs` | เก็บบันทึกประวัติการเข้าทำงานและความเคลื่อนไหวต่างๆ ของแอดมินและกิจกรรมหน้าบ้านของลูกค้า |
| `point_history` | บันทึกประวัติธุรกรรมแต้มเข้า-ออกของสมาชิกรายคนอย่างละเอียด |
| `notifications` | ระบบส่งข้อมูลการแจ้งเตือนสดสำหรับแอดมินและลูกค้า |

## 🚀 ขั้นตอนการติดตั้งและรันใช้งานภายในเครื่อง (Local Installation)

### 🛠️ สิ่งที่ต้องเตรียมความพร้อม
1.  ติดตั้งโปรแกรมจำลองเว็บเซิร์ฟเวอร์ **XAMPP** (แนะนำเวอร์ชันที่ใช้ PHP 8.1 หรือสูงกว่า)
2.  เปิดใช้งาน MySQL Database

### 💻 ขั้นตอนลงโปรแกรม
1.  **คัดลอกไฟล์โปรเจกต์:** นำโฟลเดอร์โปรเจกต์ `FitGear` ไปวางไว้ใต้ไดเรกทอรีเว็บของ XAMPP:
    ```bash
    C:\xampp\htdocs\FitGear
    ```
2.  **เปิดเซิร์ฟเวอร์:** เปิดโปรแกรม **XAMPP Control Panel** แล้วคลิกปุ่ม **Start** ที่บริการ **Apache** และ **MySQL**
3.  **ตั้งค่าสภาพแวดล้อม (.env):**
    *   คัดลอกไฟล์ `.env.example` ในโฟลเดอร์หลักแล้วเปลี่ยนชื่อเป็น `.env`
    *   เปิดไฟล์ `.env` ด้วยโปรแกรมแก้ไขข้อความ (Text Editor) แล้วแก้ไขข้อมูลการเชื่อมต่อฐานข้อมูล และ API Keys ต่างๆ (เช่น SMTP, LINE Token, AI API Keys) ตามสภาพแวดล้อมที่ใช้งานจริง
4.  **นำเข้าฐานข้อมูล (Import Database):**
    *   เปิดเว็บเบราว์เซอร์ไปที่ลิงก์: `http://localhost/phpmyadmin`
    *   กดสร้างฐานข้อมูลใหม่ (New Database) โดยตั้งชื่อว่า `fitness_db` และเลือก Collation เป็น `utf8mb4_general_ci`
    *   คลิกที่ฐานข้อมูล `fitness_db` -> กดเมนู **Import** ด้านบน -> เลือกไฟล์ `fitness_db.sql` ในเครื่อง -> กดปุ่ม **Import** (นำเข้า) ด้านล่างสุด
5.  **เปิดใช้งานเว็บไซต์:** พิมพ์ URL ด้านล่างนี้ในบราวเซอร์ของคุณเพื่อเริ่มต้นช้อปปิ้ง:
    ```url
    http://localhost/FitGear/index.php
    ```
